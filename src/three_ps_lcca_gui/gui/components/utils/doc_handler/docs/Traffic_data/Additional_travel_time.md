# Additional travel time

Additional travel time refers to the extra time incurred by travelers as a result of rerouting of vehicles caused by construction or maintenance activities.

$$\text{Additional travel time} = \frac{\text{Additional reroute distance}}{\text{Speed}}$$

For example:
- Additional reroute distance = 0.175 km
- Speed = 20 km/hr
- Additional travel time = 0.175 / 20 × 60 = 0.525 minutes
