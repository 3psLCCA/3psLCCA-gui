# Carriageway width

As per Clause 101.55 of IRC:5 2024 (Standard Specification and Code of Practice for Road Bridges, Section-I General Features of Design Eighth Revision )  
Width of carriageway is the minimum clear width measured at right angles to the longitudinal center line  of the bridge between inside faces of the crash barrier/kerbs/median. For undivided carriageway, it is measured between inner faces of the crash barrier/kerbs/median.
