# Footpath

As per Clause 101.58 of IRC:5 2024 (Standard Specification and Code of Practice for Road Bridges, Section-I General Features of Design Eighth Revision )  
A footpath is a type of thoroughfare on bridge structure that is intended for use only by pedestrians.  
When a footpath is provided, its clear width shall not be less than 1.5 m. For urban and populated areas having large concentrations of pedestrian traffic, the width of the footpath shall be suitably increased.
